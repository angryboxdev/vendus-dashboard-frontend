# ui-legacy (congelado)

Cópia do kit `src/components/ui` tal como estava antes do Design System Mezza
(origin/main de 2026-10-12). Existe só para os ecrãs antigos (RH atual)
manterem exatamente o aspeto anterior enquanto o Design System se aplica ao
Novo RH.

- **Não usar em código novo** — o kit é `src/components/ui`.
- Não evoluir: corrigir aqui só o que partir; quando um ecrã antigo migrar
  para o Design System, passa a importar de `src/components/ui`.
- Quando nenhum ecrã o importar, apaga-se a pasta.
